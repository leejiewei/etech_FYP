What "local AI" means

Chat assistants such as ChatGPT run on someone else's computers: what you type is sent over the internet, and heavy use is billed. A local model is downloaded once and runs on your own PC with free tools such as Ollama or LM Studio. Nothing you give it leaves the machine, and it works offline.

An agent is a model that does more than chat: it can read a folder of documents, run steps in order and use other programs on the PC to finish a task.

What people use one for

  • Coding help — explaining, writing and reviewing code inside the editor.
  • Documents — summarising reports, pulling figures out of invoices, drafting replies.
  • A private assistant — questions about your own files that you would not upload.
  • Automation — repeating office tasks, such as sorting files or filling in templates.

What the hardware needs

The graphics card matters most, and on the card, its memory (VRAM): the whole model has to fit in it to run at a usable speed.

Rough guide to graphics memory, for 4-bit models in Ollama or LM Studio

  • System memory (RAM): 16GB is the least we would suggest; 32GB leaves room for the tools around the model and lets a model that does not quite fit spill over, slowly.
  • Storage: a model is a 4 to 20GB download, and most people keep several. An NVMe SSD of 1TB or more loads them quickly.
  • Power and cooling: a long AI task keeps the graphics card at full load, like a game that never stops. The PC Builder checks the power supply has the headroom for it.

This table is general guidance, not a benchmark of our PCs. Which models run, and how fast, depends on the model, the software and its settings. No PC runs every model; ask us before you buy if you have a particular one in mind.
